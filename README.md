# 具身智能·生活体验创意站

基于 Flask + SQLite + 单页 HTML 的生活痛点收集与创意分享平台，集成 Qwen 大模型自动生成改进建议。

## 核心功能

- **用户注册** — 昵称 + 头像，本地存储
- **发布痛点想法** — 支持分类、场景、痛点描述、期望体验、情绪标签、地点标记
- **AI 自动生成建议** — 调用 Qwen 模型（qwen3.8-max）为每个痛点生成改进建议
- **点赞 / 同感 / 评论** — 社交互动机制，增强社区共鸣
- **排行榜** — 按获赞数排名，展示热门痛点
- **奖励阶梯** — 称号系统，激励用户持续参与
- **痛点热区** — 按地点统计高频痛点分布

## 技术栈

- 后端：Flask 3.1
- 数据库：SQLite
- 前端：单页 HTML + CSS + JavaScript
- AI：阿里云百炼平台（qwen3.8-max）

## 快速启动

```bash
pip install -r requirements.txt
python app.py
```

访问 http://127.0.0.1:5000

## 部署

项目已部署至阿里云函数计算（FC），支持通过自定义域名访问。
